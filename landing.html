🔬 Architecture

How SemiBot was built

We identified critical failure modes in existing AI chatbots (ChatGPT, Claude) for financial analysis and designed SemiBot to solve them from the ground up.

1
LangGraph Agentic Pipeline
Built on LangGraph with MemorySaver — a stateful multi-node graph where each factor runs as a parallel tool call via RunnableParallel, then aggregates into a single scoring state.
2
Deterministic Scoring (No Hallucination)
The LLM scores factors qualitatively (-10 to +10). Python applies domain-expert weights (summing to 100) to calculate UP%/DOWN% mathematically — the LLM never outputs probabilities directly.
3
RAG Supply Chain Intelligence
FAISS vector store + HuggingFace sentence-transformers indexes the full ASML→TSMC→NVIDIA→Micron causal chain with MMR retrieval for supply disruption signals.
4
Real-time API Integration
Live data from FRED API (CPI, PPI, Fed rate), yfinance (fundamentals, technicals), SEC EDGAR (insider transactions), and DuckDuckGo (news sentiment).
5
Streamlit UI + Email Summary
Dark-theme Streamlit interface with follow-up Q&A, session history, and automated email report generation via Gmail SMTP.
Problems with ChatGPT & Claude for Finance
Why existing AI chatbots fail at real-time equity analysis — and how SemiBot solves each one.
⚠️
Hallucinated Probabilities
ChatGPT and Claude fabricate percentage predictions with no mathematical basis. SemiBot's deterministic weighting eliminates this — probabilities come from Python, not the LLM.
⚠️
Stale Knowledge Cutoff
General LLMs don't know last week's FOMC decision or yesterday's NVIDIA earnings. SemiBot pulls live data from FRED, yfinance, and news APIs on every query.
⚠️
No Domain-Specific Causal Chain
Generic AI doesn't understand ASML→TSMC→NVIDIA→Micron supply dependency. SemiBot's RAG system encodes this entire causal chain as a searchable vector store.
⚠️
Inconsistent Factor Weighting
ChatGPT weights factors differently every session. SemiBot locks domain-expert weights (Geopolitics: 9, Fed Rate: 8, Insider Selling: 7) for reproducible analysis.

A Hallucination-Resistant Deterministic-Weighted Multi-Factor RAG Agent for Semiconductor Equity Directional Prediction

Raj Tejpal Khatik
MSc Applied AI · University of Warwick · Target: ACM FinNLP Workshop
Abstract
We present SemiBot, an 18-factor agentic RAG system for semiconductor equity directional prediction. Existing LLM chatbots such as ChatGPT and Claude exhibit critical failure modes when applied to financial prediction tasks: they hallucinate probability estimates, rely on stale training data, and lack domain-specific causal chain knowledge. SemiBot addresses these limitations through a novel decoupled architecture where LLM qualitative scoring is separated from quantitative probability calculation, with domain-expert weights applied deterministically in Python to eliminate hallucination.

Key contribution: The LLM scores each of 18 causal factors on a -10 to +10 scale qualitatively. Python then applies locked domain-expert weights (summing to 100) to calculate UP%/DOWN% probabilities mathematically. The LLM never outputs probabilities directly — eliminating the hallucination problem that affects all existing financial AI chatbots.

Problem Statement
General-purpose LLMs fail at real-time semiconductor equity analysis for four reasons: (1) hallucinated probability estimates with no mathematical grounding, (2) knowledge cutoffs preventing access to current market data, (3) absence of semiconductor supply chain causal knowledge (ASML→TSMC→NVIDIA→Micron dependency chain), and (4) inconsistent factor weighting across sessions. SemiBot was designed to solve each of these problems systematically.
Architecture
SemiBot is built on LangGraph with MemorySaver for stateful conversation management. The 18 factors are executed in parallel via RunnableParallel, each as a LangChain tool calling live APIs (FRED, yfinance, SEC EDGAR, DuckDuckGo). A FAISS vector store indexed with HuggingFace sentence-transformers encodes the semiconductor supply chain causal document, retrieved via MMR for supply chain factor analysis. The scoring node aggregates all 18 factor outputs and passes them to GPT-4o-mini for qualitative scoring, after which Python applies locked weights to produce the final UP%/DOWN% prediction.
18-Factor Framework with Weights
The framework covers four categories: Macroeconomic (CPI, PPI, Fed Rate, USD Index, Energy Prices), Fundamental (P/E Ratio, Market Cap, Earnings Guidance, Insider Selling, Beta), Market Intelligence (Sector Rally/SOXX, Technical Signal, Analyst Ratings, Sell-the-News), and External Signals (Geopolitics/Hormuz, Supply Chain RAG, News Sentiment, Capital Rotation, Competitor Contagion). Key weights: Geopolitics (9), Supply Chain (9), Fed Rate (8), Competitor Contagion (8), Insider Selling (7), Sell-the-News (7), CPI (7).
Results
SemiBot was evaluated on five semiconductor tickers: MU (Micron), NVDA (NVIDIA), AMD, INTC (Intel), and TSM (TSMC). The deterministic weighting architecture produced consistent, reproducible predictions across sessions. Real-time data integration via FRED, yfinance, and news APIs ensured predictions reflected current market conditions rather than stale training data.
